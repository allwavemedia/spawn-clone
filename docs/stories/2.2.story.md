## **Story Statement**

**As a music producer, I want to immediately hear generated MIDI patterns through built-in sounds, so that I can quickly evaluate musical ideas without setting up external instruments.**

## **Acceptance Criteria**

1. **AC1:** AudioPreviewEngine renders MIDI patterns in real-time with < 5ms latency
2. **AC2:** Three built-in sound types (piano, synth, bass) automatically match generation type
3. **AC3:** Preview playback integrates seamlessly with DAW transport and tempo sync
4. **AC4:** Audio processing maintains real-time thread safety with lock-free communication
5. **AC5:** Preview engine supports pattern looping and transport control (play/stop)

### **Data Models**
**MIDIPattern Structure** [Source: docs/architecture.md#Core Domain Models]:
- `notes`: Collection of Note structs with `pitch`, `velocity`, `startTime`, `duration`
- `lengthInBeats`: Total pattern length in musical beats (e.g., 16.0 for 4-bar pattern)
- `metadata`: Map storing key, scale, tempo used for generation

**GenerationParameters Structure** [Source: docs/architecture.md#Core Domain Models]:
- `key`: Musical key (C, G#, etc.)
- `scale`: Musical scale (Major, Minor, Pentatonic)
- `tempo`: BPM value
- `rhythmicComplexity`: 0.0-1.0 pattern density
- `generationType`: Melody, Chords, Bassline

### **API Specifications**
**AudioPreviewEngine Interface** [Source: docs/architecture.md#Audio Preview Engine]:
- `processBlock(AudioBuffer&, MidiBuffer&)`: Renders audio for current preview
- `startPreview(MIDIPattern)`: Begins playback of given pattern
- Dependencies: MIDIProcessor integration
- Technology Stack: C++, JUCE DSP modules

**Integration with PluginProcessor** [Source: docs/backlog.md#Story 2.2]:
- PluginProcessor owns AudioPreviewEngine instance
- Calls rendering method within processBlock callback
- Lock-free queue communication for MIDI pattern data

### **Component Specifications**
**Built-in Synthesizer Implementation** [Source: docs/backlog.md#Task 2.2.2-2.2.3]:
- Use `juce::Synthesiser` with basic wavetable voice
- Three sound types: piano, synth, bass
- Automatic sound selection based on `generationType` parameter
- Simple but musical synthesis suitable for pattern evaluation

**UI Integration Requirements** [Source: docs/backlog.md#Task 2.2.5]:
- "Preview" button sends selected MIDIPattern to AudioPreviewEngine
- Lock-free queue for UI to audio thread communication
- Real-time parameter updates without audio thread blocking
